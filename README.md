## Structuur / Structure

Elk nieuw onderwerp of platform krijgt een eigen map op het hoogste niveau (bijv. `microbit/`, `minecraft/`, `web/`, `python/`). Binnen elke map staat een eigen `README.md` met uitleg en eventuele media in `media/`.

Each new topic or platform gets its own top-level folder (e.g., `microbit/`, `minecraft/`, `web/`, `python/`). Inside each folder is its own `README.md` with documentation and any media in `media/`.
