# Micro:bit Projects

Games written in MakeCode Python for the BBC micro:bit 5×5 LED matrix.

## Projects

### 1. Tetris — [`tetris/main.py`](./tetris/main.py)
Classic Tetris implementation for the micro:bit featuring randomized tetrominoes, line clearing, and score tracking.

- **Button A:** Move 1 column left
- **Button B:** Move 1 column right
- **Button A + B:** Rotate piece (and restart after Game Over)

### 2. Space Shooter — [`space-shooter/main.py`](./space-shooter/main.py)
Arcade shooter along the bottom LED row where falling debris must be shot down before reaching the ground.

- **Button A:** Move left
- **Button B:** Move right
- **Button A + B:** Fire bullet (and restart after Game Over)
