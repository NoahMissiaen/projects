# Micro:bit Projects

Games written in MakeCode Python for the BBC micro:bit 5×5 LED matrix.

## Projects

| Project | Description | Directory |
| :--- | :--- | :--- |
| **Tetris** | Stack falling blocks, clear full rows, and track your score | [`tetris/`](./tetris/) |
| **Space Shooter** | Shoot falling debris from the bottom row | [`space-shooter/`](./space-shooter/) |
| **Dino Game** | Jump over randomly spawning cacti | [`dino-game/`](./dino-game/) |
| **Snake.io** | Eat blinking food to grow without hitting walls or yourself | [`snake.io/`](./snake.io/) |
| **Bounce Ball** | Break bricks by bouncing a ball off your paddle | [`bounce-ball/`](./bounce-ball/) |
| **Flappy Bird** | Fly through 2-LED pipe gaps against gravity | [`flappy-bird/`](./flappy-bird/) |
| **Spaceship** | Steer up and down through narrow 1-LED wall gaps | [`spaceship/`](./spaceship/) |
| **Simon Says** | Memorize and repeat growing sequences of LED symbols | [`simon-says/`](./simon-says/) |
