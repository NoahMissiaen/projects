# Coin Rush (BBC micro:bit)

Een kantelspel met de accelerometer voor het 5×5 LED-scherm van de BBC micro:bit, geschreven in MakeCode Python ([`main.py`](./main.py)).

## Hoe het werkt

- Kantel de micro:bit in 4 richtingen om jouw vaste stipje over het scherm te laten rollen.
- Pak de knipperende muntjes voor **1 punt** per stuk.
- Ontwijk het bewegende balkje van 2 LEDs breed dat diagonaal door het veld stuitert en steeds sneller gaat naarmate je score stijgt.
- Raakt de vijand jou, dan verschijnt `GAME OVER` gevolgd door je score.

## Besturing

| Actie | Invoer |
| :--- | :--- |
| Speler bewegen | **Micro:bit kantelen** (links / rechts / voor / achter) |
| Opnieuw starten *(bij Game Over)* | **Knop A of B** |

# Coin Rush (BBC micro:bit)

An accelerometer tilt game for the BBC micro:bit 5×5 LED matrix, written in MakeCode Python ([`main.py`](./main.py)).

## How it works

- Tilt the micro:bit in 4 directions to roll your solid LED dot across the screen.
- Collect the blinking coins for **1 point** each.
- Dodge the 2-LED enemy bar bouncing diagonally across the arena, which speeds up as your score grows.
- Getting hit triggers `GAME OVER` followed by your final score.

## Controls

| Action | Input |
| :--- | :--- |
| Move player | **Tilt micro:bit** (left / right / forward / back) |
| Restart game *(on Game Over)* | **Button A or B** |
