# Space Shooter (BBC micro:bit)

Een arcade shooter voor het 5×5 LED-scherm van de BBC micro:bit, geschreven in MakeCode Python ([`main.py`](./main.py)).

## Hoe het werkt

- Je bestuurt een schip op de onderste LED-rij en schiet kogels recht omhoog.
- Bovenaan verschijnen brokstukken die langzaam naar beneden vallen.
- Elke voltreffer levert **1 punt** op.
- Zodra een brokstuk de onderste rij bereikt, verschijnt `GAME OVER` gevolgd door je eindscore.

## Besturing

| Knop | Actie |
| :--- | :--- |
| **A** | 1 stap naar links |
| **B** | 1 stap naar rechts |
| **A + B** | Kogel afvuren |
| **A of B** *(bij Game Over)* | Opnieuw starten |

# Space Shooter (BBC micro:bit)

An arcade shooter for the BBC micro:bit 5×5 LED matrix, written in MakeCode Python ([`main.py`](./main.py)).

## How it works

- You control a ship along the bottom LED row and fire bullets straight upward.
- Debris spawns at the top and slowly falls down the screen.
- Every hit scores **1 point**.
- If any debris reaches the bottom row, `GAME OVER` is shown followed by your final score.

## Controls

| Button | Action |
| :--- | :--- |
| **A** | Move 1 step left |
| **B** | Move 1 step right |
| **A + B** | Fire bullet |
| **A or B** *(on Game Over)* | Restart game |
