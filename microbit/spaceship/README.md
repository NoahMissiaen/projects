# Spaceship (BBC micro:bit)

Een precisie-tunnelspel voor het 5×5 LED-scherm van de BBC micro:bit, geschreven in MakeCode Python ([`main.py`](./main.py)).

## Hoe het werkt

- Je bestuurt een ruimteschip en stuurt zelf omhoog en omlaag door smalle openingen van **1 LED** groot in aankomende muren.
- Elke gepasseerde muur levert **1 punt** op en het spel wordt geleidelijk sneller.
- Bots je tegen een muur, dan verschijnt `GAME OVER` gevolgd door je score.

## Besturing

| Knop | Actie |
| :--- | :--- |
| **A** | 1 vakje omhoog |
| **B** | 1 vakje naar beneden |
| **A of B** *(bij Game Over)* | Opnieuw starten |

# Spaceship (BBC micro:bit)

A precision tunnel flyer for the BBC micro:bit 5×5 LED matrix, written in MakeCode Python ([`main.py`](./main.py)).

## How it works

- You pilot a spaceship manually up and down through narrow **1-LED** gaps in incoming walls.
- Each cleared wall awards **1 point** and the game gradually speeds up.
- Crashing into a wall displays `GAME OVER` followed by your score.

## Controls

| Button | Action |
| :--- | :--- |
| **A** | Move 1 row up |
| **B** | Move 1 row down |
| **A or B** *(on Game Over)* | Restart game |
